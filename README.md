# Mi primer proyecto Android

Este proyecto es una aplicación móvil responsiva desarrollada para Android que demuestra la adaptación multi-idioma y el uso de gráficos redimensionables 9-Patch.

## Características

* **Soporte Multidioma:**
  * Español (Predeterminado)
  * Inglés
  * Francés
  * Alemán
* **Diseño Responsivo:** Implementado con `ConstraintLayout` para adaptarse a cualquier tamaño y orientación de pantalla.
* **Fondo Redimensionable:** Uso de recurso Nine-Patch (`.9.png`) para escalar el fondo sin deformar la figura principal.
